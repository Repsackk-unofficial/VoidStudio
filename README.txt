VOIDFORM — One Page tattoo studio
FILES: index.html, style.css, script.js
RUN: keep all three files in one folder and open index.html.
FEATURES: 12 CSS-made flash patterns, interactive hover states, category filters, detail modal, responsive layout, mobile navigation, services section, FAQ accordion, contact CTA.
CUSTOMIZE: update email, Instagram, location, studio name and copy in index.html. Design tokens are at the top of style.css in :root.
NOTE: Fonts are loaded from Google Fonts; offline mode uses fallback fonts.

OVERSIGIL UPDATE: dodano sekcję wielkoformatowego arkusza i mocniejszy kierunek wizualny w chłodnym fiolecie/kobalcie. Nie przenoś samego HTML bez folderu assets — obraz jest używany z assets/voidform-oversigil-flash.png.
